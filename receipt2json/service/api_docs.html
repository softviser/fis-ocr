Yükle Arşiv API Dokümanı OpenAPI (JSON)

Fiş OCR API

Asenkron kuyruk modeli: görsel gönderilir → anında job_id döner → sonuç job_id ile sorgulanır. Örneklerdeki taban adres: http://10.0.0.100:8080 — kendi sunucu adresinizle değiştirin. Makine tarafından okunabilir tanım: /openapi.json (OpenAPI 3.0; Postman/Insomnia'ya içe aktarılabilir).

Uç noktaları

POST/api/jobs İş gönder — dosya yükleme (multipart)
Form alanıZorunluAçıklama
fileevetGörsel (jpg, png, webp, bmp, tiff)
modehayırtwo_stage (varsayılan) | direct
ocr_modelhayırÖrn. glm-ocr:latest

Yanıt 202: {"job_id":"...","status":"queued","queue_position":1,"status_url":"/api/jobs/..."}

POST/api/jobs/base64 İş gönder — base64 / pano görseli (JSON)
JSON alanıZorunluAçıklama
dataevetBase64 gövde veya data:image/png;base64,... data-URL
filenamehayırUzantı tür tespitinde kullanılır
mode, ocr_modelhayırMultipart ile aynı
GET/api/jobs/{job_id} Sonuç sorgulama (polling, ~2 sn aralık önerilir)

Durumlar: queued (+ queue_position) → processing → done (+ result, elapsed_seconds) | error.

Çok fişli karede result: {"_multi": true, "receipt_count": 3, "receipts": [...]}

Güven kuralı: _suspect yok + _warnings boş + _tax_check.valid → otomatik onaylanabilir; aksi halde insan kontrolü.

GET/api/jobs Arşiv listesi — filtre: limit, status, q

?limit=100&status=done&q=KEBAP — q dosya adı veya sonuç JSON'u içinde arar. Her satırda summary (firma, toplam, tarih, şüpheli) ve elapsed_seconds bulunur.

GET/api/jobs/{job_id}/image İşe ait orijinal görsel

Şüpheli işlerin insan kontrolünde kullanışlıdır.

DELETE/api/jobs/{job_id} İşi ve görselini kalıcı sil

Geri alınamaz. Yanıt: {"deleted": "job_id"}

GET/api/stats Analiz süresi istatistikleri

done_count, avg_seconds, avg_seconds_last10, min_seconds, max_seconds, by_status

GET/health Sağlık kontrolü

{"status":"ok","queue_size":0,"worker_count":1,"max_upload_mb":20,"retention_days":30}
